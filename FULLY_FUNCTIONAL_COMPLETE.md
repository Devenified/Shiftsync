- **POST /api/shifts** - Create new shifts

- **POST /api/leave-requests** - Submit leave requests
- **GET /api/team-members** - Get available team members
- **GET /api/shifts/available** - Get available shifts for workers
- **GET /api/users/me** - Get user profile data
